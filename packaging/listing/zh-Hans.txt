[ShortDescription]
让 Copilot 键做你真正想要的事。把它指向任何已安装的应用、程序、文件、文件夹或链接，指向你自己选择的键盘快捷键，或者把它变回键盘上早已消失的菜单键。连按两次可以执行与单次不同的操作，按键还能根据当前最前面的应用改变用途。后台不驻留任何东西：一次按键启动 AntiPilot，做完那一件事就退出。

[Description]
你的 Copilot 键，你的应用。

Windows 11 允许自定义 Copilot 键，但只能指向以 MSIX 打包、已签名并注册为 Copilot 硬件键提供程序的应用。几乎没有应用会去做这件事，所以“设置 > 蓝牙和其他设备 > 键盘”下的列表通常除了 Copilot 本身之外空空如也。

AntiPilot 做了。在设置中选择它一次，然后决定这个键做什么。

启动已安装的应用
“开始”菜单应用列表中的任何项目，包括 Microsoft Store 应用。从带搜索和真实图标的列表中挑选，无需查找安装路径。如果应用已经打开，AntiPilot 可以把那个窗口移到最前，而不是再启动一份；如果你正看着它，则可以将其最小化。这样一个键就成了在最常用的东西之间进出的方式。

启动程序、文件、文件夹或链接
任意路径或网址，可附带参数和起始文件夹。%USERPROFILE% 之类的环境变量会被展开。

发送键盘快捷键
任意组合键，发送给你正在使用的窗口：Ctrl+Shift+Esc 打开任务管理器，Win+V 打开剪贴板历史记录，Print Screen、媒体键，或者 F13 到 F24，供那些监听键盘上并不存在的按键的宏软件使用。按下快捷键即可录制，或者直接选用预设。

用作菜单键
现代键盘上消失的那个上下文菜单键。AntiPilot 发送的是真正的按键，因此会为当前有焦点的对象打开上下文菜单，与右键单击完全一样。

打开快速启动面板
一个以键盘为中心的简短列表，列出你常用的东西。输入即可筛选，按 1 到 9 直接运行某一项，按 Esc 关闭。操作会在面板关闭之后执行，所以快捷键会落在你原本使用的窗口上。

一个键，多种用途

连按两次可以执行与单次不同的操作：同一个键上的第二项功能，代价是 AntiPilot 需要短暂等待，以判断你指的是哪一种。此功能默认关闭，等待时长可调，因为这个延迟是真实存在的，应该由你自己决定是否接受。

规则还可以根据最前面的应用改变按键的用途：在编辑器中作菜单键，在浏览器中发送快捷键，在其他地方启动你惯用的应用。

不碍事

一次按键启动 AntiPilot，做完那一件事就退出。没有任何东西驻留在内存中等待按键，除非你还没有设置过，否则不会弹出任何窗口。如果你希望随手能用，一个开关就能在通知区域放上图标，并在登录时把它带回来。此开关默认关闭。

设置窗口按照 Windows 11 的样式打造：左侧导航、设置卡片，以及你自己的主题色。它会随你切换浅色与深色主题，一眼就能看出按键当前是否指向 AntiPilot，并可直接跳转到 Windows 中设置该项的页面。你的配置可以导出为文件，并在另一台电脑上导入。

支持你的语言

英语、俄语、西班牙语、简体和繁体中文、巴西葡萄牙语、土耳其语、日语、韩语、阿拉伯语、印度尼西亚语和希腊语。AntiPilot 默认跟随 Windows 的语言；对阿拉伯语，它会镜像整个窗口，而不只是翻译文字。

同样支持 Win+C

键盘上没有 Copilot 键？Windows 会在按下 Win+C 时发送相同的信号，AntiPilot 同样会响应。

开放源代码

采用 MIT 许可证。完整许可证文本随应用提供，可在“关于”中查看。

系统要求

Windows 11，版本 22621 或更高。请在“设置 > 蓝牙和其他设备 > 键盘 > 快捷键 > 自定义键盘上的 Copilot 键 > 自定义”中选择一次 AntiPilot。

须知

Windows 会阻止发往以管理员身份运行的窗口的模拟按键，因此当此类窗口位于最前时，菜单键和键盘快捷键操作不会有任何反应。这是 Windows 的安全规则，应用无法绕过。

AntiPilot 只改变 Copilot 键启动的内容。它不会重新映射其他按键，也不会从你的电脑上移除 Copilot。

[ReleaseNotes]
一个键，多种用途。

- 发送任意键盘快捷键：Ctrl+Shift+Esc、Win+V、Print Screen、媒体键，或供宏软件使用的 F13 到 F24。按下快捷键即可录制，或直接选用预设。
- 为连按两次设置独立的操作，与单次按键区分开。
- 根据最前面的应用改变按键的用途。
- 打开快速启动面板：输入以筛选，按 1 到 9 运行某一项，按 Esc 关闭。
- 把已经打开的应用移到最前，而不是再启动一份；如果你正看着它，则将其最小化。

全新的设置窗口，按照 Windows 11 的样式打造：左侧导航、设置卡片，以及你自己的主题色。它会随你切换浅色与深色主题。

现已支持 12 种语言：英语、俄语、西班牙语、简体和繁体中文、巴西葡萄牙语、土耳其语、日语、韩语、阿拉伯语、印度尼西亚语和希腊语，默认跟随 Windows 的语言。阿拉伯语会镜像布局。

其他改进：可导出和导入配置，方便在电脑之间迁移；操作失败时改用通知提示，而不是抢占焦点的对话框；每次按键的启动也更快了一点。
